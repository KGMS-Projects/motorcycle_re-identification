Matching settings

Camera timing and direction

How the two recordings relate in time. Auto reads recording start times from file names such as 20261106_141615.mp4.

Decision thresholds

Accept needs a combined score at or above the first value (a clear winner needs 0.10 less). Below the second value a pair is rejected. Candidates closer than the margin are lookalikes.

Score weights

Missing evidence (for example an unreadable plate) is left out and the rest is re-balanced.

Similarity calibration

Auto spreads similarity using this run's own pairs. Choose manual to set the cosine range yourself.
